# [77일차] 강화학습 기초와 다중 슬롯머신

## 1. 강화학습이란

강화학습(Reinforcement Learning)은 에이전트가 환경과 상호작용하면서 **보상(Reward)을 많이 얻는 행동 전략**을 학습하는 방법이다. 지도학습처럼 입력과 정답을 쌍으로 제공하지 않는다. 대신 어떤 행동을 한 뒤 환경이 돌려주는 보상을 바탕으로 행동의 좋고 나쁨을 판단한다.

| 구분 | 지도학습 | 강화학습 |
| --- | --- | --- |
| 학습 신호 | 입력 `X`와 정답 `Y` | 행동 뒤에 받는 보상 |
| 목표 | 예측값과 정답의 오차를 줄임 | 장기 누적 보상을 최대화함 |
| 예시 | 이미지 분류, 스팸 분류, 회귀 | 게임 AI, 로봇 제어, 자율주행 |

강화학습에서 중요한 점은 눈앞의 보상만 고르는 것이 아니다. 지금의 선택이 이후 상태와 미래 보상에 영향을 주므로, 앞으로 얻을 보상까지 고려해야 한다.

```text
상태 관찰 -> 행동 선택 -> 환경 변화 -> 보상 수령 -> 경험을 바탕으로 정책 개선
      ^                                                       |
      +-------------------------------------------------------+
```

## 2. 핵심 구성 요소

| 용어 | 의미 | 게임 예시 |
| --- | --- | --- |
| Agent | 행동을 선택하고 학습하는 주체 | 플레이어 캐릭터 |
| Environment | 에이전트의 행동에 반응하는 대상 | 미로, 게임 규칙, 벽 |
| State | 의사결정에 필요한 현재 상황 | 캐릭터 위치, 열쇠 보유 여부 |
| Observation | 에이전트가 실제로 관찰하는 정보 | 화면 일부, 센서 값 |
| Action | 현재 상태에서 가능한 선택 | 위, 아래, 왼쪽, 오른쪽 이동 |
| Reward | 행동 직후 받는 수치형 피드백 | 도착 `+10`, 충돌 `-1` |
| Policy | 상태에 따라 행동을 고르는 규칙 | 갈림길에서 오른쪽으로 이동 |
| Return | 미래 보상을 포함한 누적 평가값 | 한 판 동안 얻은 총 보상 |
| Episode | 시작부터 종료까지의 한 번의 실행 | 출발부터 성공 또는 실패까지 |

### State와 Observation의 차이

상태는 환경을 완전히 설명하는 정보이고, 관측은 에이전트가 실제로 받는 정보다. 예를 들어 카드 게임에서 모든 카드의 배치는 환경의 상태일 수 있지만, 플레이어가 공개된 카드만 볼 수 있다면 그것이 관측이다. 관측만으로 상태를 완전히 알 수 없는 문제도 있다.

## 3. 보상과 누적 보상

보상은 한 번의 행동에 대한 즉각적인 피드백이다. 양수 보상은 일반적으로 바람직한 결과를, 음수 보상은 피하고 싶은 결과를 나타낸다. 하지만 보상 설계가 곧 에이전트의 목표가 되므로 신중해야 한다.

```text
미로 출구 도착: +10
벽 충돌: -1
그 외 이동: 0
```

매 이동에 무조건 `+1`을 주면 에이전트는 출구로 가기보다 같은 구간을 반복 이동해 점수를 모으려 할 수 있다. 이것이 보상 설계의 함정이다.

### 희소 보상과 지연 보상

- **희소 보상(Sparse Reward)**: 대부분의 시점에는 보상이 `0`이고, 목표 달성 시점에만 보상을 받는 경우다. 미로에서 출구에 도달해야만 점수를 받는 상황이 대표적이다.
- **지연 보상(Delayed Reward)**: 현재 행동의 결과가 여러 단계를 지난 뒤에 나타나는 경우다. 바둑처럼 마지막 승패만으로 이전 수들의 가치를 판단해야 하는 문제가 여기에 해당한다.
- **신용 할당 문제(Credit Assignment Problem)**: 최종 보상에 기여한 과거 행동이 무엇인지 알아내기 어려운 문제다. 보상이 희소하거나 지연될수록 더 어려워진다.

강화학습은 일반적으로 할인율 `gamma`를 사용해 미래 보상까지 포함한 반환값(Return)을 다룬다.

```text
G_t = R_(t+1) + gamma * R_(t+2) + gamma^2 * R_(t+3) + ...
```

- `G_t`: 시점 `t`부터 얻는 누적 보상
- `gamma`: `0` 이상 `1` 이하의 할인율
- `gamma`가 작으면 가까운 보상을 더 중요하게 보고, `1`에 가까우면 먼 미래 보상도 중요하게 본다.

## 4. 탐험과 활용

에이전트는 이미 좋아 보이는 행동만 반복할 수도 있고, 아직 경험하지 못한 행동을 시도할 수도 있다. 이 두 선택의 균형이 강화학습의 중요한 과제다.

| 구분 | 설명 | 장점 | 주의점 |
| --- | --- | --- | --- |
| 활용(Exploitation) | 현재 가장 가치가 높다고 추정한 행동을 선택함 | 이미 아는 보상을 안정적으로 얻음 | 더 좋은 행동을 놓칠 수 있음 |
| 탐험(Exploration) | 새로운 행동을 시도해 정보를 얻음 | 숨은 좋은 선택을 찾을 수 있음 | 당장은 낮은 보상을 받을 수 있음 |

### epsilon-greedy 전략

`epsilon-greedy`는 확률 `epsilon`으로 무작위 행동을 선택해 탐험하고, 나머지 `1 - epsilon` 확률로 현재 가장 좋아 보이는 행동을 선택하는 전략이다.

```text
epsilon = 0.1

10%: 무작위 행동 선택(탐험)
90%: 현재 추정 보상이 가장 큰 행동 선택(활용)
```

여기서 “가장 좋다”는 실제 정답이 아니라 지금까지 관찰한 데이터로 계산한 추정치다. 따라서 초반에는 탐험이 필요하다.

## 5. 에이전트의 학습 방식

### 가치 기반 에이전트

상태 또는 상태-행동 쌍의 가치를 학습하고, 가치가 가장 큰 행동을 선택한다. Q-Learning이 대표적인 방식이다.

### 정책 기반 에이전트

행동의 가치를 따로 고르기보다, 상태를 입력받아 행동 확률을 직접 출력하는 정책을 학습한다.

### 액터-크리틱 에이전트

정책을 학습하는 Actor와 행동을 평가하는 Critic을 함께 사용한다. Actor는 행동을 선택하고, Critic은 그 선택이 얼마나 좋았는지 평가해 Actor의 학습을 돕는다.

## 6. 다중 슬롯머신 문제

다중 슬롯머신(Multi-Armed Bandit)은 강화학습의 가장 단순한 형태다. 여러 개의 슬롯머신 중 어떤 기계가 보상을 가장 많이 줄지 알 수 없는 상황에서, 제한된 횟수 안에 많은 보상을 얻어야 한다.

이번 예제의 실제 당첨 확률은 아래와 같다. 에이전트는 이 값을 직접 보면 안 되며, 선택 결과만 보고 확률을 추정해야 한다.

```python
probabilities = [0.2, 0.5, 0.1, 0.8, 0.3]
```

| 슬롯머신 | 실제 당첨 확률 | 역할 |
| --- | ---: | --- |
| 0 | 0.2 | 낮은 보상 확률 |
| 1 | 0.5 | 중간 보상 확률 |
| 2 | 0.1 | 가장 낮은 보상 확률 |
| 3 | 0.8 | 최적 슬롯머신 |
| 4 | 0.3 | 낮은 보상 확률 |

일반적인 강화학습과 달리 이 문제는 행동 뒤에 복잡한 상태 전이가 없다. 매번 어느 슬롯머신을 고를지만 결정하면 되므로, 탐험과 활용의 차이를 이해하기 좋다.

## 7. 평균 보상 추정값 업데이트

슬롯머신 `i`를 `n`번 선택했고 기존 평균 보상이 `Q`일 때, 새 보상 `reward`를 받으면 평균을 처음부터 다시 계산하지 않고 다음처럼 갱신할 수 있다.

```text
Q <- Q + (reward - Q) / n
```

이 식은 기존 평균에 새 관측값의 영향을 한 번 반영하는 방식이다. 선택 횟수 `n`이 커질수록 한 번의 결과가 평균에 미치는 영향은 작아진다.

## 8. 슬롯머신 예제 코드

아래 코드는 노트북에서 제시한 조건을 바탕으로 작성한 실행 예제다. `Random`, `Greedy`, `epsilon-greedy` 전략을 같은 환경에서 비교한다.

```python
import numpy as np


class SlotMachine:
    def __init__(self, probabilities):
        # 실제 당첨 확률은 환경만 알고 있다.
        self.probabilities = probabilities

    def play(self, machine_index):
        # 당첨이면 1, 실패면 0을 반환한다.
        return int(np.random.random() < self.probabilities[machine_index])


class BanditAgent:
    def __init__(self, machine_count, epsilon=0.0, random_only=False):
        self.epsilon = epsilon
        self.random_only = random_only
        self.counts = np.zeros(machine_count, dtype=int)
        self.values = np.zeros(machine_count, dtype=float)
        self.rewards = []

    def choose_action(self):
        # Random 전략 또는 epsilon 확률에서는 탐험한다.
        if self.random_only or np.random.random() < self.epsilon:
            return np.random.randint(len(self.counts))

        # 아직 한 번도 선택하지 않은 기계가 있으면 먼저 경험한다.
        untried = np.where(self.counts == 0)[0]
        if len(untried) > 0:
            return np.random.choice(untried)

        # Greedy 전략: 현재 평균 보상 추정값이 가장 큰 기계를 선택한다.
        return int(np.argmax(self.values))

    def update(self, action, reward):
        self.counts[action] += 1
        count = self.counts[action]
        self.values[action] += (reward - self.values[action]) / count
        self.rewards.append(reward)


def run_experiment(name, epsilon=0.0, random_only=False, steps=1000):
    environment = SlotMachine([0.2, 0.5, 0.1, 0.8, 0.3])
    agent = BanditAgent(5, epsilon=epsilon, random_only=random_only)

    for _ in range(steps):
        action = agent.choose_action()
        reward = environment.play(action)
        agent.update(action, reward)

    print(f"[{name}]")
    print("누적 보상:", sum(agent.rewards))
    print("선택 횟수:", agent.counts)
    print("추정 확률:", np.round(agent.values, 3))
    print("가장 많이 선택한 슬롯머신:", int(np.argmax(agent.counts)))
    print()


np.random.seed(42)  # 실행 결과를 재현하기 위한 시드

run_experiment("Random", random_only=True)
run_experiment("Greedy")
run_experiment("epsilon-greedy (0.1)", epsilon=0.1)
run_experiment("epsilon-greedy (0.01)", epsilon=0.01)
```

### 코드 흐름

1. `SlotMachine`은 선택한 슬롯머신의 실제 확률에 따라 `0` 또는 `1`의 보상을 반환한다.
2. `BanditAgent`는 각 슬롯머신의 선택 횟수와 평균 보상 추정값을 저장한다.
3. `choose_action()`은 전략에 따라 탐험 또는 활용 행동을 고른다.
4. `update()`는 새 보상을 받은 뒤 선택 횟수와 평균 보상 추정값을 갱신한다.
5. 실험이 끝나면 전략별 누적 보상, 선택 횟수, 추정 확률을 비교한다.

실행 결과는 난수에 따라 달라질 수 있지만, 충분히 반복하면 실제 당첨 확률이 `0.8`인 **3번 슬롯머신**을 가장 자주 선택하는 방향으로 학습되는 것이 자연스럽다. `epsilon`이 너무 크면 탐험이 많아 누적 보상이 줄 수 있고, 너무 작으면 초기에 잘못 판단한 선택에 오래 머무를 수 있다.

## 9. 정리

- 강화학습은 정답 대신 행동 결과의 보상으로 정책을 학습한다.
- 목표는 단일 보상이 아니라 미래를 포함한 누적 보상을 최대화하는 것이다.
- 탐험은 더 좋은 행동을 발견하게 하고, 활용은 현재 알고 있는 좋은 행동으로 보상을 얻는다.
- 다중 슬롯머신 문제는 상태 전이가 거의 없는 환경에서 탐험과 활용의 균형을 실험하기 좋은 문제다.
- `epsilon-greedy`는 간단하지만 실용적인 탐험 전략이며, `epsilon` 값에 따라 탐험량과 성과가 달라진다.
