# [78일차] 강화학습의 마르코프 과정과 벨만 기대 방정식

77일차에서는 강화학습의 기본 개념과 다중 슬롯머신 에이전트의 구조를 다뤘다. 이번에는 실제 슬롯머신 전략 실험 결과를 확인하고, 강화학습을 수학적으로 설명하는 마르코프 성질, MP·MRP·MDP, 할인 리턴, 벨만 기대 방정식을 정리한다.

## 1. 다중 슬롯머신 전략 실험

다중 슬롯머신(Multi-Armed Bandit)은 여러 선택지 중 어떤 선택이 가장 많은 보상을 주는지 경험으로 알아내는 문제다. 에이전트는 실제 당첨 확률을 볼 수 없으며, 행동 뒤에 얻은 보상만 이용해 각 슬롯머신의 가치를 추정한다.

```python
TRUE_PROBS = np.array([0.2, 0.5, 0.1, 0.8, 0.3])
N_STEPS = 1000
```

| 슬롯머신 | 실제 당첨 확률 |
| --- | ---: |
| 0 | 0.2 |
| 1 | 0.5 |
| 2 | 0.1 |
| 3 | 0.8 |
| 4 | 0.3 |

3번 슬롯머신의 확률이 가장 높지만, 이는 환경이 가진 정답일 뿐 에이전트는 학습 전에 알지 못한다.

> 원본 코드의 변수명은 `N_SETPS`로 작성되어 있다. 코드 안에서 같은 이름을 일관되게 사용하므로 실행은 되지만, 의미상 `N_STEPS`가 더 명확하다.

### 행동 선택과 평균 보상 갱신

에이전트는 첫 다섯 번의 행동에서 각 슬롯머신을 한 번씩 경험한다. 그 이후에는 전략에 따라 행동을 정한다.

```python
if t < 5:
    action = t
elif strategy == "random":
    action = int(rng.integers(5))
elif strategy == "greedy":
    action = int(np.argmax(estimates))
elif strategy == "epsilon":
    action = (
        int(rng.integers(5))
        if rng.random() < epsilon
        else int(np.argmax(estimates))
    )
```

보상을 받은 뒤에는 선택 횟수와 평균 보상 추정값을 갱신한다.

```python
counts[action] += 1
estimates[action] += (reward - estimates[action]) / counts[action]
```

이 식은 모든 과거 보상을 다시 더하지 않고도 새 보상을 반영해 평균을 갱신하는 온라인 평균 계산식이다.

### 실행 결과

노트북에서 `seed=2026`으로 1,000회 실행한 출력은 다음과 같다.

| 전략 | 누적 보상 | 선택 횟수 `[0, 1, 2, 3, 4]` | 추정 확률 `[0, 1, 2, 3, 4]` |
| --- | ---: | --- | --- |
| Random | 376 | `[184, 192, 189, 201, 234]` | `[0.20, 0.54, 0.10, 0.80, 0.24]` |
| Greedy | 787 | `[7, 1, 1, 990, 1]` | `[0.29, 0.00, 0.00, 0.79, 0.00]` |
| `epsilon=0.1` | 772 | `[19, 22, 19, 918, 22]` | `[0.37, 0.32, 0.05, 0.82, 0.32]` |
| `epsilon=0.01` | 791 | `[3, 2, 2, 992, 1]` | `[0.33, 0.50, 0.00, 0.80, 0.00]` |

Random 전략은 모든 슬롯머신을 비교적 고르게 선택해 확률을 관찰하지만, 가장 좋은 3번 슬롯머신을 적극적으로 활용하지 못한다. 반면 나머지 전략은 3번을 대부분 선택하며 높은 누적 보상을 얻었다.

다만 이 결과는 하나의 시드에서 얻은 결과다. Greedy 전략은 초기에 우연히 좋은 보상을 얻었을 때 잘 작동하지만, 초반 추정이 틀리면 잘못된 슬롯머신에 고착될 수 있다. `epsilon-greedy`는 일부 행동을 탐험에 사용해 이 위험을 줄인다.

## 2. 마르코프 성질

마르코프 성질(Markov Property)은 **현재 상태를 알고 있다면 미래를 설명하기 위해 과거 전체 기록이 추가로 필요하지 않다**는 성질이다.

```text
현재 상태와 현재 행동을 알면,
다음 상태의 확률을 설명하는 데 과거 기록이 추가로 필요하지 않다.
```

예를 들어 미로 게임에서 현재 위치와 열쇠 보유 여부가 상태에 포함돼 있다면, 다음 이동의 결과를 판단하기 위해 이전에 어떤 길로 왔는지까지 모두 기억할 필요가 없다. 반대로 열쇠 보유 여부를 상태에서 빠뜨리면, 같은 위치여도 문을 열 수 있는지가 달라져 현재 상태만으로 미래를 설명할 수 없게 된다.

## 3. MP, MRP, MDP

강화학습의 환경은 행동과 보상의 포함 여부에 따라 다음처럼 확장된다.

| 구분 | 구성 | 특징 |
| --- | --- | --- |
| MP | `(S, P)` | 상태와 상태 전이 확률만 존재하며, 행동 주체가 없음 |
| MRP | `(S, P, R, gamma)` | MP에 보상과 할인율이 추가됨 |
| MDP | `(S, A, P, R, gamma)` | 에이전트가 행동을 선택할 수 있음 |

### MP: Markov Process

오늘 날씨가 맑을 때 내일의 날씨가 맑음일 확률이 70%, 비일 확률이 30%라고 하자. 이 과정에는 행동을 선택하는 에이전트가 없다. 현재 상태에 따라 다음 상태가 확률적으로 정해지는 MP다.

```text
맑음 -> 맑음: 70%
맑음 -> 비: 30%
```

### MRP: Markov Reward Process

MRP는 MP에 보상을 추가한다. 예를 들어 상태 전이마다 `+10`, `-5` 같은 보상을 주고, 미래 보상에 대한 할인율 `gamma`를 적용한다.

```text
맑음 -> 맑음 -> 비 -> 맑음
 +10    +10   -5   +10
```

### MDP: Markov Decision Process

MDP에서는 에이전트가 직접 행동을 선택한다. 행동에 따라 성공 확률과 보상이 다를 수 있다.

| 행동 | 성공 확률 | 실패 확률 | 성공 보상 | 실패 보상 | 기대 보상 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 위로 이동 | 80% | 20% | `+10` | `-10` | `0.8 * 10 + 0.2 * -10 = 6` |
| 아래로 이동 | 60% | 40% | `+5` | `-5` | `0.6 * 5 + 0.4 * -5 = 1` |

강화학습의 핵심은 이런 환경에서 장기적으로 더 큰 보상을 얻도록 행동을 선택하는 정책을 학습하는 것이다.

## 4. 전이 확률은 항상 1이 되어야 한다

행동을 선택해도 결과가 하나로 고정되지 않을 수 있다. 예를 들어 로봇이 오른쪽 이동을 명령했을 때의 전이 확률이 아래와 같다고 하자.

```python
transition = {"right": 0.8, "up": 0.1, "stay": 0.1}
assert np.isclose(sum(transition.values()), 1.0)
```

확률의 합은 반드시 `1.0`이어야 한다. 10,000번 표본을 뽑은 노트북의 결과는 다음과 같았다.

```text
right 실험 비율: 0.795
up 실험 비율: 0.101
stay 실험 비율: 0.104
```

표본 수가 충분히 많아지면 실험 비율은 설정한 전이 확률인 `0.8`, `0.1`, `0.1`에 가까워진다.

## 5. 정책, 상태가치, 행동가치

- **정책 `pi`**: 현재 상태에서 어떤 행동을 고를지 정하는 규칙이다. 행동을 확률적으로 선택할 수도 있다.
- **상태가치 `V^pi(s)`**: 상태 `s`에서 정책 `pi`를 계속 따를 때 앞으로 받을 리턴의 기댓값이다.
- **행동가치 `Q^pi(s, a)`**: 상태 `s`에서 행동 `a`를 먼저 한 뒤 정책 `pi`를 따르면 앞으로 받을 리턴의 기댓값이다.

```text
V^pi(s) = 현재 상태에서 정책을 따른 기대 가치
Q^pi(s, a) = 현재 상태에서 특정 행동을 먼저 했을 때의 기대 가치
```

`V`와 `Q`는 상태나 행동만으로 정해지지 않고, 어떤 정책을 따르는지에 따라 달라진다. 교차로에서 오른쪽으로 갔을 때 목적지에 도착할 가능성이 높다면, 그 행동의 `Q`값은 높게 평가될 수 있다.

## 6. 할인율과 리턴

리턴(Return)은 현재부터 미래까지 받을 보상을 할인해 합한 값이다.

```text
G = R_1 + gamma * R_2 + gamma^2 * R_3 + ...
```

보상이 `[10, 10, 10]`일 때 할인율에 따라 계산한 결과는 다음과 같다.

| `gamma` | 계산 | 리턴 |
| ---: | --- | ---: |
| 0.0 | `10` | 10.00 |
| 0.5 | `10 + 5 + 2.5` | 17.50 |
| 0.9 | `10 + 9 + 8.1` | 27.10 |
| 1.0 | `10 + 10 + 10` | 30.00 |

`gamma`가 1에 가까울수록 더 먼 미래의 보상까지 중요하게 고려한다. 이는 미래가 현재보다 더 중요하다는 뜻이 아니라, 미래 보상을 덜 할인한다는 뜻이다.

## 7. 상태 전이 경로의 할인 리턴

에이전트가 `working`, `gym`, `home` 상태를 이동한다고 하자. `home`은 종료 상태다.

```python
TRANSITIONS = {
    ("working", "working"): ("working", 3),
    ("working", "gym"): ("gym", 5),
    ("working", "home"): ("home", 12),
    ("gym", "working"): ("working", 4),
    ("gym", "home"): ("home", 12),
}
```

노트북의 `evaluate_actions()` 함수는 불가능한 행동과 종료 상태 이후의 행동을 `ValueError`로 막고, 경로별 보상과 할인 리턴을 계산한다.

| 경로 | 보상 목록 | `gamma=0.9` 할인 리턴 |
| --- | --- | ---: |
| A: `working -> working -> home` | `[3, 3, 12]` | 15.42 |
| B: `working -> gym -> working -> home` | `[5, 4, 12]` | 18.32 |

경로 B는 이동 단계가 하나 더 많지만, 앞선 단계에서 얻는 보상이 커서 할인 리턴도 더 크다. 순차적 의사결정에서는 짧은 경로만이 아니라 각 시점의 보상과 미래 가치까지 함께 비교해야 한다.

## 8. 벨만 기대 방정식

벨만 기대 방정식(Bellman Expectation Equation)은 현재 상태의 가치를 **즉시 보상과 다음 상태 가치의 기댓값**으로 재귀적으로 계산하는 식이다.

```text
현재 가치 = 지금 받을 보상 + 할인된 다음 상태의 기대 가치
```

정책 `pi`를 따를 때 상태가치 함수는 다음과 같이 표현한다.

```text
V^pi(s) = sum_a pi(a | s) * sum_(s') P(s' | s, a)
          * [R(s, a, s') + gamma * V^pi(s')]
```

| 기호 | 의미 |
| --- | --- |
| `pi(a | s)` | 상태 `s`에서 행동 `a`를 고를 정책 확률 |
| `P(s' | s, a)` | 행동 뒤 다음 상태 `s'`로 이동할 확률 |
| `R(s, a, s')` | 상태 전이에서 받는 즉시 보상 |
| `gamma * V^pi(s')` | 할인한 다음 상태의 미래 가치 |

### 결정적 전이 예시

시작 상태에서 보상 `+2`를 받고 중간 상태로 이동한 뒤, 종료 전 `+10`을 얻는다고 하자. 할인율이 `0.9`라면 다음과 같다.

```text
V(중간) = 10
V(시작) = 2 + 0.9 * V(중간)
        = 2 + 0.9 * 10
        = 11
```

### 확률적 전이 예시

같은 행동을 했을 때 좋은 상태로 갈 확률이 50%, 나쁜 상태로 갈 확률이 50%라고 하자. 좋은 상태의 미래 가치는 `10`, 나쁜 상태의 미래 가치는 `-2`다.

```text
다음 상태 가치의 기댓값 = 0.5 * 10 + 0.5 * -2 = 4
현재 상태의 기대 가치 = 0 + 0.9 * 4 = 3.6
```

여기서 `3.6`은 실제로 한 번에 받는 보상이 아니라, 여러 가능한 결과를 확률로 가중 평균한 기대 가치다.

## 9. Home과 Bar 상태 가치 계산 과제

노트북 마지막에는 학생이 A, B, C 중 한 위치에서 출발해 `Home` 또는 `Bar`에 도착하는 환경을 벨만 기대 방정식으로 평가하는 과제가 제시되어 있다.

```text
A -> Home: 70%, A -> B: 30%
B -> A: 50%, B -> C: 50%
C -> B: 50%, C -> Bar: 50%

Home 보상: +10
Bar 보상: -10
그 외 이동 보상: 0
gamma: 0.9
```

요구사항은 A, B, C의 가치를 `0`으로 초기화한 뒤 최대 100회 반복하며 벨만 기대 방정식으로 가치를 갱신하는 것이다. 반복 전후의 최대 변화량을 비교해 값이 수렴하는지도 확인한다.

노트북은 현재 `STATES = {}`까지만 작성되어 있어 이 마지막 과제의 구현과 실행 결과는 아직 없다. 따라서 아래 질문은 구현 뒤 결과를 바탕으로 확인해야 한다.

1. A, B, C 중 가치가 가장 높은 상태는 어디인가?
2. A의 가치가 B보다 높은 이유는 무엇인가?
3. C의 가치가 음수가 되는 이유는 무엇인가?
4. 반복할수록 가치 변화량이 작아지는 이유는 무엇인가?
5. 할인율을 `0.9`에서 `1.0`으로 바꾸면 결과는 어떻게 달라지는가?

## 10. 정리

- 슬롯머신 실험은 탐험과 활용 전략이 누적 보상에 미치는 영향을 보여준다.
- 마르코프 성질은 현재 상태만으로 미래의 확률적 결과를 설명할 수 있다는 가정이다.
- MP에 보상을 더하면 MRP, 행동 선택까지 더하면 MDP가 된다.
- 할인율은 먼 미래의 보상을 현재 가치에 반영하는 비율이다.
- 벨만 기대 방정식은 다음 상태의 기대 가치를 이용해 현재 상태의 가치를 재귀적으로 계산한다.
- 마지막 Home/Bar 과제는 벨만 기대 방정식을 반복 적용하는 가치 평가 실습이며, 현재 노트북에는 구현 전 단계까지만 작성되어 있다.
