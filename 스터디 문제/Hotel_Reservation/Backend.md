## **8월 7일 Backend 시험 주제**

Node.js와 MongoDB를 활용하여 **호텔 예약 사이트(StayHub)** 의 REST API 서버를 제작하세요.

React 프론트엔드와 연동 가능하도록 구현합니다.

 

## 사용 기술

- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcrypt

## 구현 요구사항

### 1. 회원

- 회원가입
- 로그인
- 이메일 중복 확인
- 비밀번호 암호화
- JWT 인증

### 2. 호텔

- 호텔 등록
- 호텔 목록 조회
- 호텔 상세 조회
- 호텔 수정
- 호텔 삭제
- 지역 검색
- 호텔명 검색
- 가격순 정렬

### 3. 객실

- 객실 등록
- 객실 조회
- 객실 수정
- 객실 삭제

### 4. 예약

- 객실 예약
- 예약 목록 조회
- 예약 상세 조회
- 예약 취소
- 예약 날짜 중복 방지
- 예약 인원 검증

### 5. 후기

- 후기 작성
- 후기 조회
- 후기 삭제
- 별점 등록
- 예약한 사용자만 후기 작성 가능

### 6. 인증 및 권한

- JWT 인증
- 작성자만 수정 및 삭제 가능

### 7. 예외처리

- HTTP Status Code 적용
- JSON 형식 통일
- 잘못된 요청 처리
- 존재하지 않는 데이터 처리

### 8. 데이터베이스

다음 컬렉션을 설계하여 구현한다.

- User
- Hotel
- Room
- Reservation
- Review
