## **8월 7일 Frontend 시험 주제**

React를 활용하여 **호텔 예약 사이트(StayHub)** 의 프론트엔드를 제작하세요.

Node.js REST API와 연동하여 구현합니다.

##  

## 사용 기술

- React
- React Router
- Axios 또는 Fetch API
- React Hooks

##  

## 구현 요구사항

### 1. 회원

- 회원가입
- 로그인
- 로그아웃
- 입력값 검증

### 2. 호텔 목록

- 호텔 목록 출력
- 지역 검색
- 호텔명 검색
- 가격순 정렬
- 평점순 정렬

### 3. 호텔 상세

- 호텔 정보 출력
- 객실 목록 출력
- 객실 가격 출력
- 예약 가능 여부 표시

### 4. 예약

- 예약 인원 선택
- 객실 선택
- 숙박일 계산
- 총 금액 계산
- 예약 완료 화면

### 5. 예약 내역

- 예약 목록 조회
- 체크인 / 체크아웃 선택
- 예약 상세 조회
- 예약 취소

### 6. 후기

- 후기 목록
- 후기 작성
- 별점 등록
- 본인 후기 삭제
